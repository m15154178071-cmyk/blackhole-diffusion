# 注意事项 / Caution

Blackhole Diffusion 核心算法零外部依赖，但**零依赖不等于零验证**——算法自检只能确认满秩（Rank = E − V + C）和无弦性，无法证明结果接近精确 MCB。验证正确性需要基线对比：你可以自己调 iGraph 或 NetworkX 的 API 做交叉验证，也可以直接跑封装好的 `pip install igraph networkx rich && python benchmark.py`，它会自动完成 iGraph / NetworkX / Blackhole Diffusion 三方交叉审计，所有基准报告中的数据均来源于此。两阶段使用模式：开发环境装三方库跑一次 benchmark 确认无误，生产环境只带走 `blackhole_diffusion.py` 一个文件，卸掉所有依赖直接部署。基准数据基于 30 个合成图（1000–10000 边，五种随机图模型），可以据此判断你的拓扑类型是否在已知表现范围内，但不能保证任意真实图的表现与基准完全一致——建议部署前用自己的数据跑一次单图模式：`python benchmark.py your_graph.txt out.txt 黑洞弥散`。

---

Blackhole Diffusion's core algorithm has zero external dependencies, but **zero dependencies ≠ zero verification**. Self-checks can only confirm full rank (Rank = E − V + C) and chordlessness—they cannot prove proximity to the exact MCB. Verifying correctness requires a baseline comparison: either call iGraph or NetworkX APIs yourself, or run the bundled `pip install igraph networkx rich && python benchmark.py`, which automatically performs a three-way cross-audit (iGraph / NetworkX / Blackhole Diffusion). All data in the benchmark reports comes from this cross-validation. Two-phase workflow: install third-party libraries in your dev environment and run the benchmark once to confirm correctness, then deploy only `blackhole_diffusion.py` to production with zero dependencies. Benchmark data is based on 30 synthetic graphs (1000–10000 edges, five random graph models)—you can use these to judge whether your topology type falls within known performance ranges, but they do not guarantee identical behavior on arbitrary real-world graphs. Run a single-graph check with your own data before deployment: `python benchmark.py your_graph.txt out.txt`.
