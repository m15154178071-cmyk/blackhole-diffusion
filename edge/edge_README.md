# Edge Datasets / 边表数据集

## 数据格式

每行两个整数，用空格分隔，表示一条无向边：
u v

- `u`, `v`：节点编号（从 0 或 1 起始均可，不要求连续）
- 边视为无向，重复边和自环在读取时会被自动处理
- 编码：UTF-8
